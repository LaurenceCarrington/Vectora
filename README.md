# Vectora

A local 2D CAD/vector editor for drawing sticker artwork and exporting cut lines. Built with Vite, strict TypeScript, Paper.js 0.12.18, and clipper2-wasm 0.4.0. The lockfile fixes the installed dependency graph.

## Run

Requires Node.js 20.19+ or 22.12+ (verified with Node 24) and npm.

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. For a production build:

```sh
npm run build
npm run preview
```

The build runs TypeScript checking first. WASM is bundled as a hashed asset using Vite's `?url` import and a single cached initialization promise. A failed initialization disables outlines and displays an error; reload to retry. Drawing and export remain available.

## Controls

- **V / Select:** click a shape’s interior or stroke to select it; drag from empty canvas to select fully enclosed shapes. Shift-click toggles individual shapes and Shift-drag adds enclosed shapes. Hidden/locked layers are excluded. Drag any selected shape to move the entire selection; snapping applies to its combined top-left bound, preserving relative positions. Eight shared handles resize the selection; hold Shift to preserve its aspect ratio. Numeric Properties edits use combined bounds. Delete removes all selected objects in one undo step. Click empty space or press Escape to clear; Escape during a drag restores the previous selection and geometry. Sticker Outline requires one selected shape. Handles retain their screen size across zoom levels.
- Shapes have **no fill**, including drawing previews, so the grid remains visible through them. Artwork uses charcoal strokes; sticker outlines use red strokes.
- **R / Rectangle:** drag between opposite corners, in any direction. Shift makes a square.
- **C / Circle:** press at the centre and drag to set the radius.
- **E / Ellipse:** drag between opposite bounding-box corners; hold Shift for a circle. Corners follow grid snapping.
- **Y / Polygon:** drag from the centre to a vertex to create a regular polygon. Press Up/Down on the canvas to adjust sides (3–64, default 6), including during a drag. Hold Shift for 15° rotation steps. Snapping applies to the centre and circumradius so equal sides are preserved; individual vertices need not lie on grid intersections. Side count applies to new drawings. Subsequent freeform resizing may stretch a polygon.
- **Arcs menu / Centre arc (A):** the arc icon below Lines opens the two arc tools. drag from the centre to set radius and orientation; release to create an exact semicircle and enter Select. Drag Move, Rotate, Sweep and Radius handles to edit a circular arc. Radius and centre snap in mm; angles magnet to 90° increments within 4°, or 15° with Shift. Properties offers exact Radius, Start and signed Sweep (±1–359°), Semicircle 180° and Flip arc. Width/height changes preserve circularity for one arc. Nonuniform multi-selection resizing converts arcs to freeform curves. Escape/tool switching/focus loss cancels a drawing or handle drag. Undo, cut-layer transfer and open DXF export are supported; closed-shape Sticker Outline is unavailable.
- **Three-point arc (Shift+A):** in Arcs, click the start, a point along the curve, then the end. Points snap to the visible grid; a live preview shows the curve. Backspace steps back, and Escape, switching tools or losing focus cancels. Duplicate/collinear points keep the draft for correction. This restores the original arc workflow with bounds-based resizing; press V to select afterward. Supports undo, Cut Path transfer and open DXF export.
- **Delete tools:** eraser icon below Arcs. **Dissect delete (K)** removes the hovered section between existing path points or intersections. Delete rectangle edges, polygon sides, polyline segments and curved sections without crossing lines; the remaining outline stays connected and opens at the deleted section. A single-segment path can be removed entirely. Visible locked paths may act as boundaries, but hidden paths do not. **Line delete (Shift+K)** removes the entire clicked outline, including all contours of a compound object. Hover shows a red preview; click deletes with one-step undo. Targets must be visible and unlocked. Exact curves and layer styles survive trimming; trimmed arcs use ordinary path handles. Escape returns to Select.
- **Lines menu:** the line icon below Shapes opens **Line (L)**, **Polyline (P)** and **Freehand (F)**. Drag to draw a line. For a polyline, click successive vertices and press Enter or double-click to finish; Backspace removes the last vertex and Escape cancels. Endpoints snap to the visible millimetre grid; Shift constrains each segment to 45° steps. Open paths remain unfilled and are selected by their stroke. Drag endpoint handles on two-point paths to change length/direction. A horizontal or vertical path keeps its zero dimension; use endpoints to change direction. Open paths can move to Cut Path and export as open DXF polylines; Sticker Outline requires a closed shape.
- **Freehand (F):** choose Freehand in Lines, then press, drag and release to draw a smooth open stroke. Freehand follows the pointer without grid snapping or Shift constraints, even with the magnet enabled; subsequent movement and resizing use normal snapping. Strokes are unfilled, stay open and support selection, cut transfer, trimming, deletion, undo and DXF export. Escape, tool switching, pointer cancellation or focus loss cancels the draft. A click without a drag creates nothing.
- **Properties:** open the sliders button on the right; creating or selecting a shape does not open it automatically. An already open panel stays open and follows the selection. Edit X, Y, W, and H in millimetres. X/Y are the top-left geometric bounds, excluding stroke. Editable width/height must be at least 0.001 mm; a flat open path’s zero dimension is shown but disabled. Empty, non-finite, and out-of-range values are rejected.
- **Sticker Outline:** with a closed object selected, enter a positive outset (default 3 mm) and click Sticker Outline. The independent red, unfilled result goes on the Cut lines layer and becomes selected.
- **S / Snap to grid:** toggle the magnet button in the left toolbar (on by default). Snapping follows the visible minor grid spacing, including wider intervals when zoomed out. Rectangle corners, circle centres and radii, moved-object top-left bounds, and dragged resize edges snap in document millimetres. Movement preserves the grab offset and object dimensions. Shift preserves aspect ratio even when the other edge cannot land on a grid line. Numeric property entries keep their exact values. Toggling snap does not reposition existing objects or add history; it cancels an active gesture.
- **Delete / Backspace:** delete selection. **Escape:** cancel the current drawing/move/resize and restore its previous state, or clear selection when idle. Losing window focus cancels an active gesture.
- **Cmd/Ctrl+Z:** undo. **Cmd/Ctrl+Shift+Z** or **Ctrl+Y:** redo. Toolbar buttons do the same. A completed drag is one history entry; history retains the latest 100 edits.
- **Middle-button drag** or **Space + primary drag:** pan. **Wheel/trackpad scroll:** cursor-anchored zoom. Navigation prevents browser scrolling; shortcuts do not override text/number input editing. Pointer capture keeps a drag working when the pointer leaves the canvas.
- **Layers:** starts with Cut Path, Engrave Path, Construction Path and Artwork. Drag objects from expanded rows onto other visible, unlocked layers to transfer them; dragging a selected object moves the selection, while an unselected object moves alone. Valid targets have a white outline; cancelled drops make no changes. Holding a dragged object within 40px of the list’s top/bottom auto-scrolls only the list, faster toward the edge (up to 360px/s); leaving the edge, ending/cancelling the drag or losing focus stops scrolling. Transfers support Undo/Redo. Expand rows to select objects; eye and lock controls govern canvas visibility and editing. Add layer offers all four types, with unique names. The trash button confirms deletion of a layer and its contents; locked layers cannot be deleted. Add, delete, visibility, locking and transfers support Undo/Redo. New drawing and tracing start in the default Artwork layer; if deleted, add Artwork again. Drag the header or use arrow keys (2px; Shift: 10px). Raster Engrave is not included.
- **Transfer to Cut Path:** expand Artwork in Layers and drag an object onto **Cut Path**. Dragging a selected object transfers the whole selection. The same objects move to the cut layer and turn red, without changing their geometry or creating an offset or duplicate. They export as cut lines by default. The destination must be visible and unlocked. Undo restores the original layers, colours, order and selection in one step.
- **Export:** Properties → Download DXF, or File → Export DXF to open export settings. Cut and engraving paths export by default, on separate DXF layers. Enable **Include artwork on a separate layer** to include source shapes.

## Coordinates and tolerances

One Paper.js project unit is **one millimetre**. The document origin is fixed at (0, 0), with positive X right and positive Y down. View zoom and pan never change document geometry. Initial zoom is 96 / 25.4 CSS pixels per millimetre; zoom is limited to 0.1–100 pixels/mm. Canvas size follows the viewport and Paper.js scales its backing store for high-DPI displays.

The canvas fills the viewport edge to edge with no outer padding, while floating toolbars remain 24px from their respective edges. It has an origin-aligned grid with a pale blue-white background and subtle blue-gray lines, with a stronger line every **five visible cells** and no extra emphasis on the X/Y origin lines. Cells are at least **24 CSS pixels** apart; at 100% zoom this gives **10 mm cells / 50 mm major divisions**. The finest interval is 1 mm when zoomed in. The grid follows the same document-to-view transform as the artwork. Visible intervals step through 1, 5, 10, 50, 100… mm to avoid a dense blur; the footer always shows the current minor spacing. Zooming in retains 1 mm intervals. Grid lines are guides in a dedicated, locked background layer: they cannot be selected, do not enter history or DXF exports, and support optional snapping via the magnet button. Millimetres are document units; physical on-screen size depends on the monitor and browser scale.

`src/units.ts` centralizes conversion constants and tolerances. `geometrySettings.flattenToleranceMM` defaults to **0.05 mm**; `setFlattenTolerance()` accepts 0.001–0.5 mm. This is a code-level setting in this version. Flattening reconstructs independent Bézier paths with every point and handle transformed through object and ancestor matrices **before** subdivision, so the error is in document space even under non-uniform scaling. Neither source geometry nor the view is flattened or modified.

Clipper offsets use rounded joins, **0.01 mm arc tolerance**, and five decimal places of coordinate precision. Allow approximately **0.061 mm per boundary**, or **0.13 mm for an overall width/height**, from default curve flattening + arc approximation + rounding. This budget is relative to the Paper Bézier geometry; Paper's four-cubic circle itself differs from a mathematical circle by up to approximately 0.000273 × radius. DXF uses eight decimal places and removes consecutive duplicate vertices within 0.000001 mm and redundant closing vertices.

Outlines require closed, non-degenerate, simple contours. Self-intersections, doubled-back edges, and crossing/touching compound contours are rejected. Containment, not winding, identifies interior contours: holes and islands inside an enclosing silhouette are ignored. All disconnected exterior silhouettes are retained, with interacting outsets merged by Clipper. Any holes in the result are removed for the outer-silhouette cut-line operation. Results carry explicit `data.role = 'cutline'` metadata; color is not used to decide what exports. There is no live dependency on the source.

Supported coordinates are within ±1,000,000 mm; outline distances are 0.001–10,000 mm. Outline validation is quadratic and limits each contour to 12,000 vertices; complex cases can block the main thread. Features smaller than the flattening/numeric tolerances may be rejected or lost.

## DXF subset

ASCII **DXF R2000 / AC1015**, containing 2D **LWPOLYLINE** entities only. `$INSUNITS = 4` and `$MEASUREMENT = 1` identify millimetres. The `CUTLINE` layer uses DXF color 1; optional artwork goes on `ARTWORK`. Each contour is a separate entity with its own open/closed flag. Curves become line segments, with no bulges, splines, arcs, fills, text, blocks, or 3D geometry.

DXF X equals document X; DXF Y equals **negative document Y**, relative to the fixed document origin. Export never recentres around the view, selection, or bounds. Selection decorations, handles, and unfinished shapes live in a separate overlay layer and are excluded. Empty exports explain how to create a cut line or include artwork.

This subset has automated structural and dimensional tests. **Compatibility with specific cutter software or machines has not been tested.**

## Known limitations

No SVG import, text tools, node editing, boolean-editing UI, rotation control, persistence, or machine control. Refreshing loses the document. There is no autosave or project-file format. Resizing is axis-aligned; generated outlines remain independent and can be resized like other objects. The outline service and exporter accept compound paths for geometry testing, but this version has no compound-path creation UI. History excludes view navigation and selection-only changes. Chrome is the verified browser; Safari/Firefox and physical cutter workflows remain unverified.
